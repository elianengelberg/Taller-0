# Clipersgta._ — fan page de clips de GTA 6

- `playbook.md` cuenta, voz, horarios, formato bilingüe · `lanzamiento.md` plan del día del lanzamiento
- `facts.md` hechos verificados · `watchlist.md` fuentes · `idea-bank.md` ganchos y captions
- `log.md`, `scoreboard.csv`, `learning.md`, `takedowns.md` seguimiento
- `tools/editar_clip.py` editor automático (9:16, gancho EN/ES, subtítulos IA, voz IA, crédito)

Instalar: `pip install -r requirements.txt` (+ ffmpeg). Ver ejemplos con `python3 tools/editar_clip.py -h`.
